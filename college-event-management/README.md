# College Event Management System

This is a full-stack application for managing college events.

## Features
- User Authentication (Student/Admin)
- Event Creation and Management
- Event Registration
- Attendance Tracking

## Tech Stack
- Frontend: React.js
- Backend: Node.js + Express
- Database: PostgreSQL (or MongoDB as configured)

## Setup
1. Install dependencies: `npm install`
2. Setup .env file
3. Run the application: `npm run dev`
